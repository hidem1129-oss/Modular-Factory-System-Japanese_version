## このプロジェクトについて

小規模な工場工程を実際に動く物理モデルで再現し、工程の流れ、装置の役割分担、共通インターフェース、状態の記録と可視化を確認するためのプロトタイプです。

Raspberry Pi 5が工程全体を管理し、Raspberry Pi Picoの制御ノードが各装置を動かします。I²C Debuggerがノード状態と電源監視基板の測定値を取得し、SQLiteに記録した情報をGrafanaで可視化します。

同じ制御・監視基盤を、色分け仕分けとスタンプ工程で再利用しています。個々の装置だけでなく、複数分野を一つのシステムとして統合し、構成変更や実機で見つかった課題を検討することを重視しています。

## 制作者の担当範囲

本プロジェクトでは、全体構成の検討から実機での動作確認まで、以下の範囲を制作者本人が担当しています。

| 分野 | 担当した内容 |
|---|---|
| システム設計 | 全体構成、役割分担、共通インターフェース、設計判断の整理 |
| 機構 | 市販の工作部品などを使った機構の構成・組立、工程に合わせた調整 |
| ハードウェア | 回路・PCB設計、部品選定、配線構成 |
| ファームウェア | Picoの共通通信・状態管理と、モータ・サーボ・センサの固有処理 |
| 工程制御 | 仕分け・スタンプ工程の動作順序、センサや画像判定との連携 |
| 監視・記録 | I²C Debugger、状態判定、電源監視、SQLiteへの記録 |
| 可視化 | Grafanaの設定、SQL、状態・電源データの表示 |
| 実機確認 | 組み合わせたシステムの動作確認、課題の把握、改善判断 |

Raspberry Pi、モータ・サーボ・センサ、市販の機構部品、Pico SDK、Python / PyQt5、SQLite、Grafanaなどの既製品・ソフトウェア基盤を利用しています。担当範囲は、これらを用いた設計・実装・設定・統合です。

## 対象範囲

このシステムは教育、試作、設計検討のための卓上PoCです。実際の生産設備や、安全認証された産業機器として使用することを目的としていません。

ソフトウェア上の動作完了と、ワークの到達や押印品質などの物理的な結果は区別しています。安全認証、冗長化、ハードリアルタイム保証、本番向けセキュリティは現在の対象範囲に含みません。
