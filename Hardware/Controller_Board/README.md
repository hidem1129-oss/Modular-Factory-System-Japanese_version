# Controller Board：共通制御基板

Raspberry Pi Pico WHを搭載し、共通I²Cバスと装置固有の周辺基板をつなぐ基板です。同じ基板をモータ、サーボ、センサで再利用します。

## 共通バス

J1が入力、J2が次のノードへの出力で、両方とも次の6信号を扱います。

| ピン | 信号 |
|---|---|
| 1 | +5 V |
| 2 | GND_A |
| 3 | SDA |
| 4 | GND_B |
| 5 | SCL |
| 6 | E_STOP_BUS_N |

複数ノードを連鎖接続する構成です。SDA・SCLには33 Ωの直列抵抗とTVS保護があります。レベル変換、絶縁、アクティブバッファ、差動通信は提供していません。

## アドレスの設定

4ビットのDIPスイッチをGPIO18–21で読みます。ファームウェアは下位4ビットを基準アドレス0x10と組み合わせ、0x10–0x1Fを形成します。同じ設定のノードがあるとアドレスが重複します。

基板とファームウェアが扱えるアドレス範囲と、監視アプリが現在読む範囲は別です。I²C Debuggerの既定の監視対象は0x10–0x19です。

## 周辺基板との接続

J5は2×10ピンで、8本のデジタルGPIOと1本のアナログ入力を公開します。デジタル信号はGPIO2–9、ADC入力はGPIO26 / ADC0に対応します。信号の具体的な意味は、接続する周辺基板とファームウェアが定義します。

ADC入力には1 kΩと1 nFによる簡単な調整回路があります。精密増幅や物理単位への変換はこの基板では行いません。

周辺電源は、実装時に0 Ωリンクのどちらか一方を選び、5 Vまたは3.3 Vとします。実行中にソフトウェアで切り替える方式ではありません。

## 停止と復帰の役割分担

ローカル停止入力はGPIO16、ACK入力はGPIO15で、いずれもLowで有効です。共通バスにはアクティブLowのE_STOP_BUS_Nを通します。

基板は信号経路と入力を提供し、停止状態の検出、保持、共有、出力停止、復帰判断はファームウェアが担当します。ACKを押すことだけで復帰が保証されるわけではありません。

現在の構成には、ファームウェアとは独立したハードウェア強制遮断の保証はありません。基板上の停止ボタンも、密集した配置では見つけにくく操作しにくい課題があります。
