# 製作・調達資料

基板の回路図、Gerber、部品情報は英語版で管理しています。日本語版では、それぞれが何を確認する資料なのかを説明します。

## 資料の使い分け

| 資料 | 確認すること |
|---|---|
| 基板README | 用途、接続、実装状況、制約 |
| 回路図 | 電気的接続、ピン配置、部品値 |
| Gerber | PCB製造データ、外形、配線、穴 |
| BOM / DigiKey MyList | 部品型番と調達候補 |
| 部品データシート | 定格、機能、端子、特性 |

[英語版の製作一覧](https://github.com/hidem1129-oss/Modular-Factory-System/blob/main/Hardware/Manufacturing/README.md)に、各基板の説明、Gerber、DigiKey MyListへのリンクをまとめています。

## 改版と代替部品

回路図とGerberが意図した同じ改版であることを確認します。注文設定には、外形、層数、穴、厚さ、銅厚、コネクタの向き、極性、製造プレビューなどが関係します。

部品を変更する際はパッケージだけでなく、ピン配置、定格、機能、起動時の状態も確認します。特にシャント抵抗、ヒューズ、フェライトビーズ、コネクタは測定や保護、電源経路に影響します。

初回通電は英語版の段階的な確認手順を参照します。公開データは試作資料であり、完成した量産仕様や認証済みの組立手順を示すものではありません。
