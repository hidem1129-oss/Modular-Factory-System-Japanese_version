# Power Monitor Board：電源分配と測定

外部5 Vを受け、8分岐へ分配し、各分岐と主幹の測定値をホストへ提供します。電源を生成・安定化する基板ではなく、供給電源の品質と一次保護は外部電源側に依存します。

## 測定構成

3個のTCA9548Aと9個のINA219で、8分岐と1主幹を観測します。ソフトウェアがMUXの接続先を切り替えてINA219を読み、値を換算・記録します。

| 測定対象 | シャント抵抗 | 抵抗定格 |
|---|---|---|
| 各分岐 | 0.1 Ω | 2 W |
| 主幹 | 0.05 Ω | 2 W |

主幹は合計電流が流れるため、抵抗値を下げて電圧降下と損失を抑えます。チャンネルと論理ポート名の対応は、回路図とソフトウェアの設定を合わせて確認します。

## 分岐の経路

5 V主幹 → 手動スイッチ → シャント測定 → リセッタブルヒューズ → フェライトビーズ・コンデンサ → 出力コネクタ、という構成です。分岐のスイッチとLEDは、供給の切り替えと表示を担当します。

ノイズ対策は卓上負荷向けの基本的な構成です。絶縁やすべての負荷に対するノイズ抑制の保証はありません。

## 測定値が表す範囲

測定点はヒューズ、コネクタ、外部ハーネスなどの上流です。値は分岐へ入る電力を表し、アクチュエータ端子で実際に消費する電力と完全には一致しません。下流の電圧降下やコンデンサの充電電流も解釈に関係します。

現在の目的は、正常時と異常時の比較、起動時の傾向、分岐間の比較、履歴の確認です。精密な負荷端子測定を目的としていません。

## 保護と監視の違い

主幹のリセッタブルヒューズは公称保持1.5 A・トリップ3 A、分岐は保持0.5 A・トリップ約1.1 Aです。これらは精密な電流制限値ではなく、温度、時間、電流、個体差で動作が変わります。

測定値に基づく自動分岐遮断、電子式電流制限、即時短絡分離は現在のハードウェア保証に含みません。画面での負荷監視と、電源・保護回路が行う動作は別です。

## 配線とソフトウェア

ロジック・通信はPi5 Wiring Auxiliary → Power Monitor Board → Controller Boardの順に接続し、アクチュエータ電源は外部電源をJ11で受けて各分岐へ供給します。

[監視アプリ](../../Software/I2C_Debugger/README.md)が取得と記録、[Grafana](../../Software/Grafana/README.md)が履歴表示を担当します。ノード状態と電源値の自動対応付けは現時点では実装されていません。
